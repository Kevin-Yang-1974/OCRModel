# 阶段 1 复跑：覆盖度口径的预登记

**登记时间**：2026-09-20，**在本次运行之前**（本文件先于 `run_id` 尾号 `stage1_v2` 的数据提交，
git 记录即顺序证据）。
**背景**：`docs/LAYOUT_ATTENTION_PROBE_RESULT.md` §9.2 记录了阶段 1（`stage1_v1`）在预登记口径下
未通过——准确率 99.4%（目标 90%）远超，**覆盖度 46.3%（目标 50%）未达**。§9.3 的诊断表明
未达的是**门槛定义**：`top_line_mass ≥ 0.5` 是绝对份额，而一页能给一行的份额随其行数下降
（覆盖度与行数相关 −0.65），阈值把「读数不自信」与「这页行多」混在一起。

---

## 一、为什么要改口径（以及这次改动的性质）

§9.3 的扫描是在已知 `stage1_v1` 失败之后、在**同一批 check 页**上做的。据此改门槛再宣布
`stage1_v1` 通过，属于方案 §6 明令禁止的「见结果后改门槛」，**本文件不这么做**：

- `stage1_v1` 的结论**保持不变**：绝对阈值口径下未通过。
- 本文件登记的是**下一轮**的口径，并在**一批不重叠的页**上评测，使证据独立于产生失败的那批页。
- 门槛数值 2× 取自 §9.3 的扫描。这一取值的**依据是回顾性的**，本文件如实登记这一点（见第四节）。

## 二、登记的口径

| 项 | 登记值 | 依据 |
|---|---|---|
| 层 | 第 8 层 | 阶段 0 在 select 页上选（§8.2） |
| 头 | `2,3,8,10,11,12,14,15` | 同上，select 页单头准确率 ≥93% |
| 聚合 | 固定 8 头**行概率取均值** | 同上；不用逐头择优（那会让置信度变成选择器的输出） |
| **置信度量** | **`c = top_line_mass × 页行数`** | §9.3.2：去掉绝对量纲后箱间差从 32 点降到 <0.7 点 |
| **门槛** | **`c ≥ 2.0`** | §9.3.2 表；登记值 2× |
| 高置信准确率目标 | **≥ 90%** | 方案 §5 阶段 1 门槛，沿用 |
| 高置信覆盖目标 | **≥ 50%** | 同上，沿用 |
| 基准 | 准确率须高于 `保持上一行` 与 `均匀扫描` | 同上，沿用 |
| **主报告页集** | **check 页**（14 页） | 沿用；select 页不参与判定 |
| 邻域窗口 | 3 字 | 沿用 `--neighbourhood 3` |

置信度量用「相对均匀的倍数」的理由：一页有 N 行时，均匀分布下任何一行不超过 1/N，
所以 `c` 直接读作「这个读数比均匀集中多少倍」，在 10 行页与 40 行页上含义相同。
`top_line_mass` 不具备这个性质。

## 三、登记页集

- 来源：MTHv2 sparse24 **validation**（149 页），**不读 test**。
- 抽取规则：按真值长度排序后等距抽取 28 页，规则与 `stage1_v1` 完全相同——**但排除
  `stage1_v1` 已用的那 28 页**（排除清单为 `stage1_v1/validation_subset_stage.jsonl`），
  使两批页不重叠。由启动器的 `GLMOCR_PROBE_SUBSET_EXCLUDE` 按构造保证，并在运行时打印
  选取的 `page_id` 以供核对。
- select/check 划分：按同一长度序交替，各 14 页。
- **局限（如实登记）**：validation 的 149 页已用于历史探索，方案 §6 也指出「内部留出的子集
  也不是全新盲测」。排除法只保证**与产生失败的那批页不重叠**，不构成全新盲测。

## 四、这次结果该怎么读（登记在先）

| 结果 | 解读 |
|---|---|
| 覆盖与准确率**都达标** | 覆盖度未达标确实是门槛定义所致。可进入「是否做阶段 2」的判断——但要注意 `oracle_line` 尚未跑，**行级约束有没有收益仍未知**。 |
| 准确率达标、**覆盖仍不达标** | 覆盖度问题**不是**阈值造成的，而是读数在足够多的步上不够自信。应停止按现在的定位方案推进，报告缺口。 |
| **准确率不达标** | 读数的定位能力本身不成立。按方案 §5「行级也不可测则停止」，停止，不先写滤波器。 |

**不以逐头择优的聚合方式判定**（`stage1_v1` 下它两半都通过，但那是选择器的输出）。

**不做**：本次结果出来后不改本文件登记的门槛、不换页集、不改头。若需要再改，写新的登记文件
并在再下一批页上评测。

## 五、同时登记的辅助报告（描述性，不用于判定）

1. 逐页覆盖度与逐页准确率（`per_page`），以及覆盖度与行数的相关——用来检验新口径下混淆是否
   真的消失，而不是只看总体数。
2. 按行数分箱的覆盖度与准确率（`by_region_bucket` 等价物）。
3. 置信度—准确率分箱（`bands`），单调性是否保持。
4. 换行前后 / 行内（`at_row_break` / `within_row`）、漏读邻域（`near_dropped`）、
   复读邻域（`near_repeated`）、干净邻域（`clean`）。
   **复读邻域在 `stage1_v1` 上只有 0–12 字**，若本批仍无病态复读，如实记为空白而非报数。
5. 对齐压力：插入比例、歧义步、逐页插入占比——`stage1_v1` 上逐页插入中位 9.6%、最大 34.7%，
   对齐在这些页上本身就不牢靠，必须一起读。
6. 成本与接线：两臂逐页 token 一致（硬判据）+ 每页耗时。`stage1_v1` 是 +14.2%。
