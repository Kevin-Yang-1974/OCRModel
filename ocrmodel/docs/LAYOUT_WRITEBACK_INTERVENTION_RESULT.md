## 二、管线自校验

两个臂逐位复现了此前独立记录的数值，说明本次实现没有引入偏差：

- `full` 臂 `0.111608` = 归因脚本注释里记录的「同 ckpt、gate=0.0129、4M」参照值

## 三、结论

**1. 六臂结果被同一条机制完整解释：解码器只使用 `H̄`（页级共有分量），逐 patch 结构贡献为零。**

> **2026-09-19 更正（幅度混淆）**：上面「逐 patch 贡献为零」的措辞过强。算术核对：
> `spatial_share × full_inj = 0.353 × 0.0206 = 0.0072`，正等于 `spatial` 臂实测的 `inj/vt`
> ——即 `spatial` 臂是在 **0.7%** 幅度下测的，而 `full` 是 **2.06%**，差 **2.9 倍**。
> 因此「逐 patch 分量无用」与「逐 patch 分量太轻、没被听见」**没有被本次分开**。
> 已加入 `spatial_scaled` 臂（按页把 `H − H̄` 缩放到与 `‖H‖` 同幅度）并在 v5 中测完。
>
> **该混淆已由 v5 解除，且结论比原措辞更强：逐 patch 分量不只是「无用」，在等幅度下是
> 有害的。** `spatial_scaled` 的 `inj/vt = 0.0206` 与 `full` 逐位相同（幅度混淆确实被消除），
> 但 CER 反而升到 **0.116270**，比 `zero`（0.112988）还差。详见第四节。

- `shuffle` ≡ `full` **逐位相同**：破坏 patch 与上下文的对应关系，什么都没变。
- `global` ≈ `full`：只留页级均值，效果基本保留（点估计还略好）。
- `spatial` ≈ `zero`（0.112802 vs 0.112988，且显著差于 full）：只留逐 patch 结构，效果归零。

注意 `shuffle` 的逐位相同是「只有均值有用」的**必然推论**——置换保持多重集，因此保持 `H̄`
不变。它是强一致性检验，但不是独立证据。独立证据是 `spatial ≈ zero` 与 `global ≈ full`。

**2. 假说 C（注入时机 / 投影抹平）被证伪。** 实测 `in_rel = 0.0207`，与 `α·lc_norm_over_vt`
的预测值 `0.0129 × 1.6 = 0.0206` **精确吻合**；而 merger **放大** 而非衰减该扰动
（`attenuation = 3.15`，输出相对扰动 6.4%）。信号到达语言模型时不但没被吞掉，还比写入时更强。
因此瓶颈不在注入点，同一 seam 上的任何重新参数化都不会是问题所在。

**3. 方案 `LAYOUT_FUSION_REDESIGN.md` 的前提以更强的形式被否证。** 它说「布局信息进去了但
decoder 不利用」；实际是「decoder 确实利用了注入的东西，但利用的不是布局信息」——是页级
共有分量。这也解释了它引用的核心异常：随机查询分支（`lc_flat=0.008`，其 H 几乎 100% 是均值）
与训练分支（92% 是均值）注入的**均值量级相当**，因此 CER 相同。

**4. §1.1 的幅度误读得到实测确认**：真实注入幅度是视觉 token 范数的 **2.07%**，不是
「比视觉 token 还大一半」。

## 四、v5：两个未决问题都已判定

run `glmocr_layout_writeback_intervention_20260919_v5`，同一 checkpoint / 协议 / 缩放路径，
5 臂。`noise` 的 seed 缺陷已修（seed 由页面内容摘要派生，逐页不同），`spatial_scaled` 为新增臂。

seam 传递函数在 v5 复现：`in_rel=0.02070`，`out_rel=0.06364`，`attenuation=3.148637`（v2 为 3.15）。

**问题一：逐 patch 分量是「无用」还是「太轻」？——太轻被排除，它是有害的。**

`spatial_scaled` 的 `inj/vt = 0.0206` 与 `full` **逐位相同**，即幅度混淆确实被消除；
按 v2 时的猜想，若逐 patch 分量只是被淹没，等幅度下它应该追上 `full`。实际结果相反：
它 **0.116270**，不但是全部五臂中最差，比 `zero`（0.112988）还差 **0.0033**，
相对 `full` 恶化 **+0.004661**，是 `zero − full` 的 **3.4 倍**。

即：**逐 patch 分量在等幅度下不是惰性，而是对抗性的。** 把它放大到与 `‖H‖` 同幅度，
等于用一个方向错误、幅度正确的扰动替换掉原本有效的页级偏置，结果比什么都不注入更糟。
这同时解释了 v2 的 `spatial ≈ zero`：在 0.7% 幅度下它的危害小到与地板分辨不出。

**问题二：页级分量的「方向」是否承载内容？——承载。**

`global_perm` 保持范数（`inj/vt = 0.0189`，与 v2 的 `global` 一致）、保持页特异性
（仍逐页不同），只破坏隐藏维上学习到的方向。结果 **0.112876**，落在 `zero`（0.112988）
与 `noise`（0.112839）这一簇，显著差于 `full`。

**所以增益不是「任意页级特异性」带来的泛化性条件化，而是那个学到的方向本身。**
结合 v2 的 `global ≈ full`，结论是：布局分支的**全部**可用贡献是一个**页级、方向特定**的
条件向量；逐 patch 结构不但没有贡献，还会在幅度足够时主动破坏它。

**对「是否有信号可搬运」的最终回答**：逐 patch 路线上没有可搬运的信号。这不是投递问题
（attenuation 3.15 已排除），也不是幅度问题（本节的等幅度对照已排除），是内容问题。

## 五、对下一步的影响

1. **不需要再改残差注入点**（假说 C 已证伪，attenuation 3.15）。方案 §2.1/§2.2/§2.3 全部作废。
2. **逐 patch 路线（含把逐 patch 信息塞进 prompt）在内容维度上没有可用信号**：不是投递问题、
   不是幅度问题，是内容问题（第四节）。任何只是「把 `H − H̄` 换个缝再送一遍」的方案，都应当
   预期落在 `spatial_scaled` 那一侧。
3. 后处理路线（用预测阅读顺序重排输出）失去依据：布局分支并未提供可用的阅读顺序信息。
4. **前缀注入（`src/layout_ocr/prefix_injection.py`）仍然是值得做的实验，但预期要重新校准。**
   它的价值不在「换缝救回逐 patch 信号」，而在页级通道的形态优势：专用前缀位置、全注意力、
   不受残差 cap 0.03 限制，且投影零初始化（装上即与原模型逐位相同，增益可归因）。
   据此，第一次实验应当以 **`GLMOCR_PREFIX_PAYLOAD=global`（页级向量）为主臂**——
   这正是本节证据指出承载信号的那一路——再以 `queries`（逐区域）为探索臂。
   两臂共用 `zero` / `shuffle` / `noise` / `global_perm` 干预对照，判据与本文一致。
