### 描述

在本次 1024-step 架构对照的全量 validation/diagnostic 记录中，少数未选中的 seed44 后程 checkpoint 的 residual_relative_norm 略超过预设 0.01，最大值为 0.0114237471。涉及 attention@768/1024、geometry@1024 和 layout_ot@1024。

### 影响

选中的 geometry@768 三个 seed 均满足 residual_relative_norm≤0.01，且所有任务参数、checkpoint 和训练指标 finite；未发现 CUDA、OOM、NaN、Inf 或 Traceback。本现象不改变 validation-only 选点和长程有效性判定，但说明后程存在轻微残差增长。

### 处理

保留完整 run 及所有 checkpoint，不以同一 run ID 重跑；按预先规则选择 geometry@768。后续 test 必须继续遵守 selection-locked 协议。

### 备注

若后续将 residual_relative_norm≤0.01 解释为所有 checkpoint 的全局硬约束，应在报告中保留该边界，不应表述为全程均无超阈值。
