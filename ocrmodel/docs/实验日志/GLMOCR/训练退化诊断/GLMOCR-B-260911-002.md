## 当前结论边界

A1 与 plain baseline 的训练汇总一致，且 A1 natural-loop loss 没有激活，因此当前不能声称该惩罚已经改变了模型参数或学会自然脱环。A1 的 direct test 只提供了 step1024 在 plain 解码下的结果；baseline 必须在相同 fixed-final、相同 800 页 test 和相同 plain 解码下完成后，才能判断自然循环损失是否带来可测差异。
