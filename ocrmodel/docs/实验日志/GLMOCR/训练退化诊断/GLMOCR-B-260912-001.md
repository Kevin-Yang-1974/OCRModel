# GLMOCR-B-260912-001：natural predicted-loop A1 warm-start continuation

## 目的

验证仅使用真实自由生成轨迹构造循环惩罚时，累计 1024 步训练能否降低 OCR 循环；不使用 scheduled sampling、硬 EOS、循环 logits processor 或 continuation head。

## 协议

- 分支：`glm-ocr-layout-ot`。
- 模型：GLM-OCR revision `ca5d8b3e287e52589e37c28385d9655ee4372f9d`。
- 数据：MTHv2 whole-page，train `2159` 页、test `800` 页；test 只在训练完成后读取。
- seed `42`；五卡同步 DDP（GPU `0,1,2,3,4`）；global batch `5`；512 queries；geometry/full/Hungarian。
- OCR：LoRA rank/alpha/dropout `8/8/0`，adapter LR `5e-5`，decoder LoRA LR `1e-6`，plain generation，forced EOS/cycle guard 均关闭。
- 训练阶段不做 validation，selection 使用 fixed-final checkpoint；`test_used_for_selection=false`。

## 训练执行

第一阶段 `glmocr_natural_rollout_A1_warmstart256_260912_v1` 从已有 natural-loop A1 checkpoint warm-start，完成 `256` 步并保存 finite 的 `checkpoint-256`。第二阶段 `glmocr_natural_rollout_A1_warmstart256_cont768_260912_v1` 从该 checkpoint 接续 `768` 步，故累计 optimizer updates 为 `1024`。第二阶段会重新建立 optimizer/scheduler，`summary.json` 中的局部 `selected_step=768` 表示接续阶段步数，不应误读为累计步数。

第二阶段训练 summary：

| 指标 | 数值 |
| --- | ---: |
| mean official/base OCR loss | `1.087921` |
| token-weighted OCR loss | `1.159041` |
| mean natural-loop loss | `2.653688` |
| mean weighted natural-loop loss | `0.132684` |
| mean active tokens / page | `14.0117` |
| active-page ratio | `0.946614` |
| checkpoint | `checkpoint-768`，parameters/checkpoint finite |

这证明 rollout-based natural-loop 分支在该 run 中产生了非零训练信号；但它不等价于单次从基础权重连续 1024 步的 optimizer 状态续训。

## 结论与边界

本实验未通过自然循环抑制目标：虽然训练期 active ratio 非零，但自由生成循环和长度触顶均比 plain baseline 更高，CER 恶化约 `0.309`，主要表现为插入错误增加。该结果不能单独归因于循环惩罚权重，因为本实验采用了 `256+768` warm-start 接续，第二阶段重新初始化 optimizer/scheduler，且没有同起点、同一连续 1024-step optimizer 状态的 A0 对照。下一轮若继续，应先做严格同起点单次 1024-step A0/A1 对照，或固定 warm-start 方案再只改变 `lambda_loop`，并优先检查循环后续目标是否把插入分布推向更长生成。
