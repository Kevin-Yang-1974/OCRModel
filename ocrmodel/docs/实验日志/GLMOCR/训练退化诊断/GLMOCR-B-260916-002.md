# GLMOCR-B-260916-002：Q32 content-only 同起点对照训练

## 目的

在上一轮敦煌／地方志 Q32 `attention` 与 `geometry` 微调之后，使用完全相同的 source checkpoint、数据、步数和学习率补跑 `content_only`，获得同一套布局与 OCR 指标，作为无布局融合的对照。

## 协议

- 主机：`a100-yky`；五卡同步 DDP，GPU `0,1,2,3,4`；seed `42`；whole-page；Q32。
- 数据：`dunhuang_local_gazetteer_q32_v1_portable`；train/validation/test 按当前合并 Q32 协议执行。
- source：`glmocr_mthv2_sparse24_q32_layout_boxeq820_3000_from_boxeq58_a100_260916_v1/seed42/checkpoint-3000`。
- 初始化：加载 source 的 `adapter.safetensors` 与 `decoder_lora.safetensors`；残差 scale 覆盖为 `0.005`；允许 content-only 与 source geometry adapter 的 mode 字段不一致，其他 adapter 配置保持严格匹配。
- mode：`content_only`；`auxiliary_weight=0`，因此 layout loss 不参与更新，融合路径为 identity；仍保留 layout head 输出以便收集同一套 IoU/MAE 诊断指标。
- 训练：`256` 步；LR horizon `256`；warmup `216`；主／decoder LR `1e-5`／`2e-6`；layout loss profile `history_box_equalized_v2`；max eval new tokens `1536`；generation mode `loop_recovery`。
- 边界：smoke → training → validation-only selection → selection-locked test；训练、validation 和选点均不读取 test。

## 与 attention / geometry 对照

| mode | test IoU | test MAE | CER | I/D/S |
| --- | ---: | ---: | ---: | --- |
| content-only | `0.263915` | `0.068268` | `0.173582` | `482 / 486 / 1496` |

content-only 与 attention 的 CER 完全一致，但布局 test IoU 低 `0.007581`、MAE 高 `0.014455`；geometry 的布局指标和 CER 均略优于另外两组。三组的 EOS、generation limit、repeated-cycle 和 loop-detected page rate 均为 `0`，因此本轮差异不是由 content-only 额外触发生成循环造成的。

## 结论与边界

1. content-only 已按相同 256 步、相同数据、相同 source checkpoint 和主／decoder 学习率完成，可作为本轮 attention/geometry 的有效对照。
2. 在 59 页 locked test 上，content-only 与 attention 的 OCR CER 相同，但布局 IoU/MAE 较弱；geometry 在本轮短程对照中最好。
3. 该结论只覆盖一个 seed、一个 256-step checkpoint 和当前合并 Q32 test，不代表多 seed 或长程泛化结论。
