## 阶段性判断

1. `full_ddp_v1` 的 loss 平台不能单独归因于模型结构；学习率在第 432 步后固定为 `5e-6` 是明确的协议问题。
2. `no_assignment` 后 auxiliary loss 可以下降，但 OCR loss 仍在约 1.3–1.4 区间振荡，说明 assignment loss 不是当前 OCR 停滞的唯一直接根因。
3. validity/no-object head 已实现 query target、balanced BCE、transport 门控和 valid coverage 记录，但当前诊断显示它可能只学到全局 valid 概率偏置，尚未形成 query-level 选择。
4. 后续若继续架构修改，应先检查 Hungarian `query_mask`、validity head 梯度和 gated fusion 的实际写回路径，不直接扩大学习率或启动正式三 seed 全量训练。
