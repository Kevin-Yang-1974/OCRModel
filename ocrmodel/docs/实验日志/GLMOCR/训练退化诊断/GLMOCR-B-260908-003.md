## 目的

## 诊断结论

- 调度周期混淆已排除，但退化仍存在：64 步优于 identity，128 步 CER 回升到 `0.208774`，256 步进一步为 `0.208982`。
- 退化与 residual 增长同步，但 residual norm 在 256 步仍仅 `0.00243`，低于 `0.01` 阈值；gate 也远低于 `0.03` cap。
- 无效 query fusion mass 没有随 64→128 上升，invalid transport mass 基本不变，因此“无效 query 直接吞噬更多融合质量”不是首要证据。
- 当前 triage 优先级为 `query_mask/no-object`，其次为 `target-slot matching and auxiliary-loss conflict`；dtype mismatch 已排除。
- 64 步→128 步的 CER 恶化为 `+0.0018668`，且 validation assignment/order 等几何损失下降，说明辅助目标在 teacher-forcing 指标上继续变好，但 generation CER 变差，优先怀疑 query 监督覆盖/无对象 query 与 OCR 目标之间的冲突，或固定 slot 对齐方式。
