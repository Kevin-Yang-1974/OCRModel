## 诊断结论

- 64 步仍优于 identity；128 步相对 64 步恶化约 `0.0017631`，256 步又回落到优于 identity 的水平。
- invalid fusion mass 随训练下降，故 64→128 的恶化没有得到“无效 query mass 上升”的直接支持。
- residual norm 单调增大但 256 步约 `0.00607`，仍低于 `0.01` 诊断阈值；gate 仍受 `0.03` cap 约束。
- 本轮最关键的混淆因素是 LR schedule horizon：step 128 的优化状态与上一轮 max_steps=128 运行不同。因此下一步先保持 max_steps=256，新增 `lr_schedule_steps=128` 对照，再决定是否进入 loss profile 或 Hungarian matching 消融。
