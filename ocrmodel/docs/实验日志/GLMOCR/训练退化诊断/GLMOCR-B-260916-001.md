# GLMOCR-B-260916-001：Q32 box 权重等化续训与 gate=0.005 跨域微调

## 目的

验证将 box 项权重调到与 assignment loss 同量级后，MTHv2 Q32 layout 分支能否形成可复用的布局 checkpoint；随后从该 checkpoint 同时加载 Seed `42` 的 layout adapter 与 decoder LoRA，在敦煌／地方志合并数据上以残差 gate `0.005` 对照 `attention` 与 `geometry`。

## 协议

- 分支：`glm-ocr-layout-ot`；平台：`a100-yky`；五卡同步 DDP，GPU `0,1,2,3,4`。
- 模型：GLM-OCR revision `ca5d8b3e287e52589e37c28385d9655ee4372f9d`；whole-page；Q32；seed `42`。
- MTHv2 source：`sparse24` 协议，从 `glmocr_mthv2_sparse24_q32_layout_boxeq58_3000_a100_260916_v1/seed42/checkpoint-3000` 接续 `3000` 步。
- source layout loss：`history_box_equalized_v2`，box `820.0`、assignment `1.0`、order/direction `0.5`；主／decoder LR `2.5e-5`／`5e-6`。
- 跨域数据：`dunhuang_local_gazetteer_q32_v1_portable`；attention 与 geometry 从同一 source checkpoint 各自独立训练 `256` 步。
- 跨域 loss：同一 `history_box_equalized_v2`，外层 auxiliary weight `0.4`；主／decoder LR `1e-5`／`2e-6`；warmup `216`；min LR ratio `0.1`。
- 初始化：两臂均加载 `adapter.safetensors` 与 `decoder_lora.safetensors`，并将 source residual scale 覆盖为 `0.005`。attention 复用 source geometry adapter，仅对 adapter metadata 的 `mode` 字段放宽匹配，其他配置保持严格一致。
- 评估：每臂仅评估 `checkpoint-256`；先 validation-only selection，再执行 selection-locked test；最多生成 `1536` tokens。训练、validation 和选点均不读取 test。

## 结论与边界

1. box 权重等化后的 MTHv2 Q32 source checkpoint 已完整保存并可作为跨域微调起点；其 sparse24 test IoU 为 `0.446998`，不能与敦煌／地方志 test 直接横向比较。
2. gate=`0.005` 的 256 步跨域对照中，geometry 在布局和 CER 上略优于 attention，但差距很小；两臂均未出现触顶或循环。
3. 本结果只有一个 seed、一个短程 checkpoint，属于迁移与稳定性诊断，不足以宣称 geometry 已获得稳健泛化收益，也不替代多 seed 或长程正式实验。
