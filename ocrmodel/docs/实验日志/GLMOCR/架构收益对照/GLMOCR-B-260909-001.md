# GLMOCR 第二阶段 1024-step 架构收益对照

## 实验目的

在同一 GLM-OCR 基础权重和固定 R1/R2 小样本协议下，直接执行第二阶段 1024-step 对照，验证训练步数延长后是否能稳定支撑更长训练，并比较 attention、geometry 和 layout_ot 三种布局适配方式。模式与 checkpoint 只依据 validation CER 选择；本轮不读取 test。

本轮从基础权重重新开始，不续训既有 256-step checkpoint。数据规模、整页输入协议和验证集保持不变。

## 数据与模型协议

- 数据协议：r1_r2_128_seed42_v1；128 页 train、64 页 validation。
- 输入协议：原始整页图像加 OCR prompt；模型内部生成布局 queries，bbox、阅读顺序和书写方向不作为推理输入。
- 训练结构：32 queries、Hungarian matching、full layout loss、auxiliary weight 0.2。
- 数值与执行：FP32 adapter/transport/loss、BF16 backbone、fast processor、Glm46VImageProcessorFast、torchvision backend、math SDP、关闭 TF32、严格 deterministic。
- 基础权重 revision：ca5d8b3e287e52589e37c28385d9655ee4372f9d。

- 未发现 CUDA error、OOM、NaN、Inf 或 Traceback。

边界记录：全量诊断中，少数未选中的 seed44 后程点 residual relative norm 略超 0.01，最大值为 0.0114237471，涉及 attention@768/1024、geometry@1024 和 layout_ot@1024。这属于轻微后程残差增长，不构成运行不稳定；按“最终选中模式/检查点”的选择口径，geometry@768 通过阈值。若将该阈值解释为所有 checkpoint 的全局硬约束，则本轮应标记为存在边界，而不是宣称全程无超阈值。

## 结果判断

1. geometry@768 为三 seed 平均 validation CER 最优组合，CER 0.1897773629；相对于 geometry 在 ≤256 范围内的最佳点 0.2069418516 有明显改善。
2. geometry 的 512/768/1024 长程候选中，768 为最佳点，且至少 2/3 seed 相比其短程最佳点改善，满足“大步数带来有效收益”的预设判定。
3. attention 的长程最佳点为 512、三 seed 中仅 1 个改善；layout_ot 的长程最佳点为 768、仅 1 个 seed 改善，二者均不满足长程有效性规则。
4. 结论不是“所有模式都适合延长到 1024 steps”，而是：在当前固定确定性协议和数据规模下，geometry 支持延长训练，验证集选择应停在 768；1024 不是最优 checkpoint。
5. layout_ot 后程退化未用于替代其他模式结果，也未改变预先规定的选择规则。
